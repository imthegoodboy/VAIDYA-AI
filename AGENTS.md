# Agent Instructions

Use these project-local instructions before changing this app.

1. For app feature work, bug fixes, UI polish, backend changes, or frontend/backend integration, read `.agents/SKILLS/SKILL.MD` first.
2. For "production-ready", final review, release, demo, hackathon submission, or PR-readiness work, also read `.agents/SKILLS/production-readiness-review/SKILL.md`.
3. Use `.agents/SKILLS/references/project-memory.md` for reusable AI Vaidya project knowledge that is too detailed for the main skill.
4. After substantial work, update the skill or project memory only when the task reveals durable knowledge future agents should reuse.
5. Do not add a task-by-task changelog, secrets, private user data, local credentials, temporary debug notes, or one-off implementation details to the skills.
6. Respect higher-priority system and developer instructions whenever they differ from these project notes.
